# Nice Airport Transfer Fare System: Technical Documentation

MkDocs source for a short technical description of how fixed fares, booking data and service coverage are organised for private transfers from Nice Côte d'Azur airport (NCE), based on the public pages of https://taxiaeroportnice.com.

Build locally:

    pip install -r requirements.txt
    mkdocs build

Published with Read the Docs (configuration in `.readthedocs.yaml`).
