# Booking workflow and data fields

This page describes the reservation as a data record: which fields the booking form on [https://taxiaeroportnice.com](https://taxiaeroportnice.com/) collects, how the record moves from request to confirmation, and which time limits apply to changes. Sources are the homepage form and the [FAQ](https://taxiaeroportnice.com/aide-faq/), read on 20 November 2026.

## Input fields

| Field (label on the form) | Type | Allowed values |
|---|---|---|
| Direction | Choice | One way (Aller Simple) or return (Aller Retour) |
| Pickup address | Text | Airport terminal, hotel, private address |
| Destination address | Text | Any served destination |
| Departure date | Date | Calendar |
| Departure time | Time | Quarter hour steps |
| Return date, return departure time | Date, time | Shown when "return" is selected |
| Passengers | Number | 1 to 8 |
| Luggage | Number | 0 to 8 |

Optional information given at booking includes the flight number, a child seat request, ski or golf equipment, a pickup at a different terminal, or a passenger travelling on someone else's booking (their name and phone number are then entered). Multiple stops can be requested as an option, with a supplement.

## From request to confirmation

1. The form calculates the price for the addresses and date entered. The fare table shows the starting point of that calculation, so the quote for a specific address can be slightly different from the rounded "from" figure.
2. The passenger confirms. A summary is sent by SMS, WhatsApp and email.
3. Before the pickup, the driver's name and phone number are sent by SMS or WhatsApp.
4. After the trip, a detailed invoice is sent by email.

Booking by phone on +33 7 53 54 87 71 follows the same steps. The FAQ recommends booking at least two hours ahead to secure a driver.

## Change and cancellation windows

| Event | Time limit before pickup | Channel |
|---|---|---|
| Change to the booking | At least 12 hours | Phone or email |
| Free cancellation | Up to 24 hours | Not specified in the FAQ |
